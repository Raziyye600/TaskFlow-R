# TaskFlow

TaskFlow brauzerdə işləyən, Azərbaycan dilində sadə tapşırıq idarəetmə tətbiqidir.

## İşə salmaq (Windows)
1. ZIP faylını kompüterə yüklə və üzərinə sağ düymə ilə bas.
2. **Extract All / Hamısını çıxart** seç.
3. Açılan `TaskFlow` qovluğuna daxil ol.
4. `index.html` faylına iki dəfə bas.
5. Tətbiq Chrome, Edge və ya Firefox-da açılacaq.

Quraşdırma və internet bağlantısı tələb olunmur. Tapşırıqlar brauzerin LocalStorage yaddaşında saxlanılır. Eyni brauzer profilindən istifadə et; brauzer məlumatlarını təmizləsən, tapşırıqlar silinə bilər.

## Mövcud funksiyalar
- Tapşırıq yaratmaq, silmək və tamamlandı kimi işarələmək
- Son tarix və prioritet təyin etmək
- Status üzrə filtrləmək və axtarış
- Kanban görünüşündə status dəyişmək
- Açıq/tünd görünüş
- Mobil ekranlara uyğunlaşma

## Texnologiyalar
HTML5, CSS3, Vanilla JavaScript ES Modules, LocalStorage.
